Metadata Manager for SD webui Image

このアプリケーションは、Stable Diffusion Web UI automatic1111版で生成された画像のメタデータを管理するためのツールです。

主な機能：
1. 画像ファイルのドラッグ＆ドロップ、または選択によるデータの読み込み
2. メタデータの表示と編集
3. BLIP-2を使用した画像の解析
4. 編集したメタデータの画像への保存
5. メタデータのCSVファイルへの保存
6. 個人情報を削除した画像コピーの作成

使用方法：
- 画像をドロップエリアにドラッグ＆ドロップするか、「ファイル」メニューから開きます。
- メタデータを表示・編集します。
- 必要に応じてBLIP-2で画像を解析します。
- 編集したデータを画像に保存したり、CSVファイルに出力したりできます。

詳細については、ドキュメンテーション（準備中）を参照してください。
