Metadata Manager for SD webui Image

このアプリケーションは、Stable Diffusion Web UI automatic1111版で生成された画像のメタデータを編集するためのツールです。
他にも画像ファイルの解析などにもご使用いただけます。

主な機能：
1. 画像ファイルのドラッグ＆ドロップ、または選択によるデータの読み込み
2. メタデータの表示と編集（webuiの仕様に合わせ、メタデータ内のparametersタグを読み込みます）
3. BLIP-2,CLIP,MobileNetなどのAIを使用した画像の解析
4. 編集したメタデータの画像への保存
5. メタデータのCSVファイルへの保存（webui automatic1111版のstyles.csvを想定）
6. 個人情報を削除した画像コピーの作成（アップロード時などにプロンプト情報などを削除したい場合に使用します）

使用方法：
1. 画像をドロップエリアにドラッグ＆ドロップするか、「ファイル」メニューから開きます。
2. 自動的にメタデータを表示します。（無い場合は表示されません）
3. 表示されたプロンプトデータを編集できます。
- 必要に応じてBLIP-2などのAIモデルで画像を解析します。
4. 編集したメタデータを画像に保存したり、webuiのstyles.csvファイルに追記する事が可能です。

解析モデルについての説明：
・CLIPによる解析について
- CLIPは画像と与えられたキーワードの関連度の高さを分析するためのモデルです。
- そのためCLIPでの解析は設定画面よりキーワードを設定してお使いください。デフォルト値ではほとんど意味がありません。
- CLIPは一度モデルをメモリ上にロードさえしてしまえばスムーズに動作するはずです。

・BLIP-2による解析について
- BLIP-2は解析結果を自然言語（英語）で表示してくれるモデルです。
- BLIP-2で使用するモデルは10GB以上のサイズがあるため、VRAMは4GB以上、メインメモリは16GB以上を搭載したPCでの利用を推奨します。
- VRAMが4GB以下の場合でもスムーズに処理できるように4bit量子化の設定が可能です。こちらの設定については設定画面より有効化してお使いください（初期値では使用しない設定になっています。）ただし解析の精度は多少下がる可能性があります。

・MobileNetV3による解析について
- MobikeNetV3による解析はsmallモデルとlargeモデルの2種類があります。
- この解析モデルはとても軽量なため、どちらを選ばれても基本的には高速で動作すると思われます。
- ただし解析の精度は低めのため、CLIPが動作しないような限られた環境でのみお使いいただくことを想定しています。

※その他の注意点
- このアプリケーションはユーザーのホームディレクトリの[.metadata_manager]フォルダの下に設定ファイルやモデルデータ、ログファイルなどを保存します。使用するPCを変更する場合はこのフォルダをバックアップしてください。
- AIを使用した解析は基本的にディスクリートGPUを搭載したPCでの利用を推奨します。特にBLIP-2モデルについてはより多くのVRAMが必要になるためビジネス向けのPCなどでの利用は想定しておりません。
- 当アプリケーションではtorchライブラリを使用するため、初回ロード時には数分かかることがあります（PCの性能に依存します）。
- 同様にアプリ起動後の最初の解析時にはAIモデルのダウンロードや展開を行うため、しばらくお待ちいただく必要があります。待ち時間については回線速度やPCの性能に依存します。
- もし何らかの理由で処理が進まない場合はお手数ですがこのソフトウェアを一度終了させて、再度処理をお試しください。
