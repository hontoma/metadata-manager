Metadata Manager for SD webui Image

このアプリケーションは、Stable Diffusion Web UI automatic1111版で生成された画像のメタデータを編集するためのツールです。
他にも画像ファイルの解析などにもご使用いただけます。

主な機能：
1. 画像ファイルのドラッグ＆ドロップ、または選択によるデータの読み込み
2. メタデータの表示と編集（webuiの仕様に合わせ、メタデータ内のparametersタグを読み込みます）
3. BLIP-2,CLIP,MobileNetなどのAIを使用した画像の解析
4. 編集したメタデータの画像への保存
5. メタデータのCSVファイルへの保存（webui automatic1111版のstyles.csvを想定）
6. 個人情報を削除した画像コピーの作成（アップロード時などにプロンプト情報などを削除したい場合に使用します）

使用方法：
1. 画像をドロップエリアにドラッグ＆ドロップするか、「ファイル」メニューから開きます。
2. 自動的にメタデータを表示します。（無い場合は表示されません）
3. 表示されたプロンプトデータを編集できます。
- 必要に応じてBLIP-2などのAIモデルで画像を解析します。
4. 編集したメタデータを画像に保存したり、webuiのstyles.csvファイルに追記する事が可能です。

※注意
- 設定データはユーザーのホームディレクトリの[.metadata_manager]フォルダの下にconfig.iniファイルを作成し保存します。使用するPCを変更する場合はこのファイルをバックアップしてください。
- AIを使用した解析はディスクリートGPUを搭載したPCでの利用を推奨します。特にBLIP-2モデルについてはより多くのVRAMが必要になるためビジネス向けのPCなどでの利用は想定しておりません。
- 当アプリケーションではtorchライブラリを使用するため、初回ロード時には数分かかることがあります（PCの性能に依存）。
